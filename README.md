# Olive Design

Site da Olive Design: identidade visual estratégica para negócios com história, propósito e vontade de crescer. Jaguaruna/SC, atendimento em todo o Brasil.

**Marcas que criam raízes.**

## Como editar

- **Depoimentos e portfólio:** `config.js` (instruções dentro do arquivo). Campos vazios não aparecem no site.
- **WhatsApp e e-mail do formulário:** `config.js`.
- **Cores e fontes:** topo do `estilo.css`.
- **Textos das seções:** `index.html`.

## Ver no computador

```
python -m http.server 4173
```

Depois abra http://localhost:4173.
